# NexusIDE v1.0 Implementation Plan

> **For agentic workers:** execute task-by-task with `superpowers:executing-plans`. Steps use checkbox syntax.

**Goal:** A browser-based IDE (edit, preview, run small web/JS/TS/React projects) with a browser-contained sandbox.

**Architecture:** Pure domain layer (file tree, search, fuzzy, run state) -> persistence (IndexedDB, ZIP) ->
Zustand stores -> React UI. User code never runs in the app origin: it runs in a `sandbox`-attribute iframe
(opaque origin, no `allow-same-origin`, CSP `connect-src 'none'`) loaded from `/sandbox.html`; console
programs run in a Worker created *inside* that iframe so a timeout can kill them by removing the iframe.

**Tech Stack:** React 18.3.1, TypeScript 5.9 strict, Vite 5.4, Monaco 0.50 (direct, no CDN), Sucrase (TS/JSX
transpile + ESM->CJS), idb, JSZip, Zustand, xterm, Vitest + happy-dom + fake-indexeddb, Playwright-core + system Edge.

**Spec:** `08_BROWSER_BASED_IDE_V1_0.md` + `UNIVERSAL_APPLICATION_AGENT_RULEBOOK.md` (provided by the owner in chat).

## Global Constraints
- TS strict; line <= 120; file <= 300 (split before 400); function <= 50 (error at 80); complexity <= 10; nesting <= 3; <= 4 params.
- "Never run arbitrary user code directly inside the privileged API server process" -> there is no server; static hosting only.
- "No claim of full VS Code parity, universal language support or unrestricted package installs."
- "Preview iframe sandbox/CSP and secure origin separation; prevent token exfiltration."
- No fake data presented as real (the draft's fake "extensions marketplace" is removed). No telemetry. No accounts.
- Integrated terminal only because a genuinely isolated environment exists (sandboxed Worker REPL) - it is a JS REPL, not a shell.
- Do not commit/push (rulebook rule 9). Milestone "Git commit" gates are reported as pending owner approval.
- Report only validations that actually ran.

## Decisions (ADR summary - full text in docs/ARCHITECTURE.md)
1. **Sandbox = browser-contained**, not WebContainers (cross-origin-isolation headers, third-party licence/service) and not
   remote containers (needs infra that cannot be verified here). Consequence: no Node, no npm install, no shell, no
   hard RAM cap. Stated in KNOWN_LIMITATIONS.
2. **Runnable languages:** HTML/CSS/JS/TS/JSX/TSX/JSON in a DOM preview; JS/TS console programs in a Worker.
   Python/Rust/Go/Java/C++ are edit-only (highlighting), with an explicit "cannot run here" surface.
3. **Persistence:** IndexedDB `nexuside` v1 stores `nodes`, `drafts` (crash journal), `backups` (last 5), `meta`.
4. **Identity:** warm graphite + ember accent (no purple), Instrument Sans + JetBrains Mono (OFL, self-hosted).
   Fontshare was not used: its licence page could not be read (see docs/DESIGN_REFERENCES.md).

### Task 1 (M1): Scope, security design, domain primitives
**Files:** Create `src/domain/{errors,limits,languages}.ts`, `docs/ARCHITECTURE.md`, `docs/DESIGN_REFERENCES.md`; Test `src/domain/*.test.ts`.
**Produces:** `type Result<T> = {ok:true;value:T}|{ok:false;error:AppError}`; `AppError{code,message}`;
`LIMITS`; `languageForPath(path): LanguageInfo{id, runnable:'preview'|'script'|'none'}`.
- [ ] Tests: `languageForPath('a.tsx')` -> typescript/preview-capable; `'x.py'` -> `runnable:'none'`; unknown ext -> plaintext.
- [ ] Implement; write threat model + permission matrix + persistence schema/migration + screen map in ARCHITECTURE.md.

### Task 2 (M2): File tree domain
**Produces:** `createNode(s,{parentId,name,kind,content?})`, `renameNode(s,id,name)`, `deleteNode(s,id)`, `pathOf(s,id)`,
`fromPaths(files: Record<path,string>)`, `toPaths(s)` - all `Result`-returning, immutable.
- [ ] Tests: reject `''`, `'.'`, `'..'`, `'a/b'`, `'a\\b'`, NUL, >255 chars, duplicate sibling (case-insensitive), depth > 10, >500 files,
      file > 1 MB; delete folder removes descendants; rename keeps id; `fromPaths` creates missing parent folders; rejects `../x`.
### Task 3 (M2): Search + fuzzy
- [ ] Tests: regex `a*` / `^` / `(?:)` terminates (zero-length matches); invalid regex -> structured error; 500-result cap; whole-word; fuzzy ranks prefix > subsequence.
### Task 4 (M2): Persistence
**Produces:** `openWorkspaceDb()`, `loadWorkspace()`, `saveNodes(prev,next)` (diff writes), `putDraft/clearDrafts/listDrafts`,
`createBackup(label)/listBackups/restoreBackup`, `wipeAllData()`; `sanitizeNodes(unknown[]) -> {nodes, dropped}`.
- [ ] Tests (fake-indexeddb): roundtrip; corrupt records dropped not thrown; orphans re-parented; QuotaExceeded -> `{code:'QUOTA_EXCEEDED'}`;
      backup retention = 5; v0->v1 migration fixture.
### Task 5 (M2): ZIP
- [ ] Tests: export->import roundtrip equal; entry `../evil` and absolute paths rejected; >100 files/ >20 MB expanded -> `ZIP_TOO_LARGE`; empty folder survives; non-UTF8 binary skipped with warning.
### Task 6 (M2): Stores + undo + shell + Monaco + tree + tabs + palette + shortcuts + search UI + autosave/recovery
- [ ] Tests: store undo/redo of delete/rename; autosave debounce writes once; recovery banner when draft newer than node; palette keyboard nav.
### Task 7 (M3): Sandbox + runner + preview + console + terminal
**Produces:** `bundle(files, entry) -> Result<{code}>`; `buildPreviewDocument(files, htmlPath, runId) -> Result<string>`;
`createSession(host): {run, stop, onEvent}`; protocol `SandboxEvent = ready|console|error|done` validated by `parseSandboxEvent`.
- [ ] Tests: bundler resolves `./x`, `./x.ts`, `./dir/index.tsx`, json, css; cycles OK; unknown bare import -> `UNSUPPORTED_DEPENDENCY`;
      doc builder inlines css/js, escapes `</script`, injects CSP meta + bridge first; protocol rejects wrong shape/oversize/foreign runId.
- [ ] E2E (Edge): hostile program tries fetch / WebSocket / parent.document / top.location / indexedDB / localStorage / cookie /
      sendBeacon / Image beacon / dynamic import(URL) / window.open -> every one fails, parent IndexedDB intact.
      `while(true){}` console program is killed at timeout and Run works again; 3 concurrent sessions isolated.
### Task 8 (M4): Templates, diagnostics, polish, error surfaces
- [ ] Templates html/css/js, ts, react (runtime versions read from vendored package), blank. Problems panel from Monaco markers.
      Error surfaces: unsupported runtime, chunk-load failure (offline) with retry, quota, corrupt data. Responsive <720px bottom-nav layout.
### Task 9 (M5): Security review, CI, release
- [ ] `pnpm run ci` (type-check, lint, test+coverage, build, verify-dist). E2E suite. Screenshots (desktop + 360px).
      Docs: README, FEATURE_MATRIX, TEST_REPORT, RELEASE (hash), KNOWN_LIMITATIONS, FEATURE_LOG. Fresh-clone checklist run in a temp copy.

## Review Focus (inputs the spec implies but does not test)
1. Zero-length regex matches in search (original code looped forever) - Task 3.
2. ZIP entries with `../`, absolute paths, or missing directory records - Task 5.
3. Two tabs / two windows editing the same workspace (last-writer-wins; show notice via `BroadcastChannel`) - Task 6.
4. A 5 MB single-line minified file in the editor (large-file mode: minimap off, wrap off, no markers) - Task 8.
5. Persisted settings from an older/invalid version (unknown theme string) must fall back to defaults, not crash - Task 6.
